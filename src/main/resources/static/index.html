📋 API Endpoint Reference

Products  /products

Method Endpoint Description
GET /products Get all products (FakeStore)
GET /products/{id} Get a specific product by ID (FakeStore)
POST/products Create a product (FakeStore)
PUT /products/{id} Update a product (FakeStore)
DELETE/products/{id} Delete a product (FakeStore)
GET /products/db Get all products from DB
GET /products/db/{id} Get product by ID from DB
POST/products/db/create Create a product in DB
GET /products/db/product/categories/{id} Get product with its category
GET /products/db/product/{minprice} Get products above a minimum price
GET /products/db/product/productname/{name} Search products by name

Categories  /categories

Method Endpoint Description
GET /categories Get all categories (FakeStore)
POST/categories/create Create a category in DB
GET /categories/db/{id} Get specific category by ID from DB
GET /categories/db/products/{id} Get all products by category ID
GET /categories/db/category/products/{id} Get category with all its products
